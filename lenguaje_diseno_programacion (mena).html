Lenguajes de Diseño
y Programación

Explora los principales lenguajes usados en el desarrollo web, aplicaciones de escritorio y diseño digital. Conoce su sintaxis, propósito y nivel de dificultad.

Los lenguajes web son los pilares de todo lo que vemos y usamos en Internet. Se dividen en frontend (lo que el usuario ve) y backend (la lógica del servidor). Muchos proyectos modernos combinan varios de ellos.

HTML
HTML 5
HyperText Markup Language · 1993

Lenguaje de marcado que define la estructura de las páginas web. No es un lenguaje de programación, sino de marcado semántico: etiquetas describen el contenido.

app.js
// Función para saludar al usuario
function saludar(nombre) {
  const hora = new Date().getHours();
  const turno = hora < 12
    ? "Buenos días"
    : "Buenas tardes";
  return `${turno}, ${nombre}!`;
}

console.log(saludar("Estudiante"));
// → "Buenas tardes, Estudiante!"

using UnityEngine;

public class Personaje : MonoBehaviour {
  public float velocidad = 5f;

  void Update() {
    float h = Input.GetAxis("Horizontal");
    transform.Translate(
      h * velocidad * Time.deltaTime,
      0, 0);
  }
}
